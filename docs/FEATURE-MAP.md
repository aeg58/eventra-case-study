# Eventra Feature Map

| Product area | Capabilities | Engineering focus |
|---|---|---|
| Dashboard and calendar | Multiple date ranges, event states, conflict checks | Fast operational overview |
| Reservations | Create, edit, cancel, participants, dynamic fields | Consistent validation and modularity |
| Customers | Active and prospective records | Reusable customer context |
| Finance | Payments, cash boxes, receipts, reservation finance | Traceable operational records |
| Reporting | Revenue, reservation, and customer filters | Date-aware aggregation |
| Access control | Users, roles, and permissions | Role-based authorization |
| Documents | Contracts and collection receipts | Configurable PDF output |
| Communications | Email, SMS, WhatsApp, prepared messages | Provider-ready settings |
| Administration | Venues, packages, products, tax, pricing, theme | Business-controlled configuration |
| Reliability | Database migration, backup, and restore scripts | Operational recoverability |

## Deliberate Exclusions

- Public source code and deployment configuration
- Production URLs and credentials
- Customer names, contact data, and financial records
- Online payment processing claims
- Placeholder or planned modules presented as completed features
